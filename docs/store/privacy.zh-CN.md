# Microsoft Store 隐私说明

## 应用处理的数据

映窗打开用户从本机选择的图片文件。应用不会上传图片内容，不包含广告，也不会发送使用数据分析信息。

为了提供最近打开记录，映窗会在本机的 `%LOCALAPPDATA%\YingView\settings.json` 中保存最近打开的最多8个文件路径。该文件也保存语言、查看方式、主题、文字大小和工具栏偏好。

图片对比窗口会在当前会话中记录“保留”和“待定”标记。用户导出标记时，映窗会在用户选择的位置生成 CSV 文件，其中可能包含图片文件名和路径。应用不会发送这些标记或导出的文件。

用户对当前图片使用 **Delete** 或 **Del** 时，映窗会请求 Windows 将文件移入回收站。此功能支持本机固定磁盘；网络驱动器和可移动磁盘暂不支持。查看、对比、旋转和镜像都不会改动图片数据。

发生未处理的应用错误时，映窗可能在 `%LOCALAPPDATA%\YingView\errors.log` 中记录诊断详情，其中可能包含文件路径或异常携带的其他信息。这些文件保留在本机，应用不会将其发送给开发者或服务器。用户可以通过 Windows 文件资源管理器删除本地 YingView 数据。

## 数据共享与保留

Windows 独立版可在首个窗口显示后查询项目的 GitHub Releases，自动查询最多每天一次；可在菜单中关闭“自动检查更新”，也可手动检查。GitHub 会接收到网络连接及普通请求头，应用不会在请求中包含图片或本地文件路径。选择“下载更新”后才下载，选择“安装并重启”后才安装。微软商店版通过 Microsoft Store 更新，不使用独立版的 GitHub 更新器。

应用不会向开发者或第三方传输图片、偏好设置、对比标记、CSV 导出或诊断详情。本机偏好设置和诊断文件会保留，直到用户清空或删除它们。CSV 文件保留在用户保存的位置。

客户端不含应用内购买或支付处理。

## 联系方式

支持与隐私问题可通过[GitHub Issues](https://github.com/shixi-11/yingview/issues)联系。请勿在公开问题中附上私密图片、文件路径或支付信息。
