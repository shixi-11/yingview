# Microsoft Store 商店页文案（简体中文）

## 应用名称

映窗

## 简短介绍

顺滑缩放、文件夹浏览与并排对比，让看图更从容。

## 详细介绍

映窗为图片留出清爽宽阔的观看空间。打开图片或文件夹，即可在最大化窗口中按比例完整查看；小图会自动放大，滚轮缩放也会围绕指针位置进行。文件夹图片按文件名自然顺序排列，需要时可打开缩略图栏。

并排对比两张图片时，缩放和平移会保持同步。你可以选择深色、浅色或棋盘格背景，为图片标记“保留”或“待定”，并将本次标记导出为本地 CSV 文件。

映窗提供四种界面风格，可调整配色和文字大小，也可切换紧凑工具栏。主题支持以 JSON 格式导入和导出。

映窗客户端可免费用于个人和商业用途，具体以随附的客户端许可为准；源代码适用单独条款。图片在本机打开和对比。映窗不会上传图片，不含广告，也不会发送使用数据分析信息。使用 Delete 或 Del 可将当前图片移入本机固定磁盘的 Windows 回收站。

## 主要功能

- 最大化窗口按比例完整显示，也会自动放大小图
- 围绕指针缩放、拖动画面，并按文件名自然顺序浏览文件夹
- 默认收起、可随时显示的缩略图栏
- 两张图片并排查看，缩放和平移保持同步
- 深色、浅色和棋盘格对比背景，会话标记与本地 CSV 导出
- 四种界面风格、配色和文字大小调整，以及免费 JSON 主题导入和导出
- 支持动图查看，并受单张图片处理限制约束
- 支持 PNG、JPEG、GIF、WebP、AVIF、BMP、TIFF 和 ICO 格式
- 支持简体中文和英文界面
- 客户端可免费用于个人和商业用途
