# Microsoft Store 商店页文案（简体中文）

## 应用名称

映窗

## 简短介绍

完整看图、细看差别，随手预览自选背景色的本地图片查看器。

## 详细介绍

打开图片或文件夹，让画面清楚展开。映窗默认最大化，按比例放大小图，保留完整画面。文件按名称自然顺序排列，滚轮围绕指针缩放，需要时再展开紧凑的缩略图栏。

两张图片可以并排对照，同步缩放和平移。为图片标记“保留”或“待定”，再把本次标记导出为本地 CSV，方便继续整理。

检查作品和透明边缘时，可选择黑、白、灰、棋盘格或任意背景颜色。紧凑调色盘与图片并排，拖动即可实时看效果，确认保存、取消恢复。

选择界面风格，调整配色和文字大小，切换紧凑工具栏，或导入、导出 JSON 主题。旋转和镜像查看不会覆盖原图；Delete/Del 可将支持的本机固定磁盘文件移入 Windows 回收站。

映窗采用 AGPLv3 免费开源，图片在本机处理，没有广告和使用数据分析。提供中文和英文客户端，自愿打赏用于支持维护，不影响功能使用。

## 主要功能

- 按比例完整显示与实际像素查看
- 围绕指针缩放、平移及自然顺序翻图
- 可折叠的紧凑缩略图栏与全屏浏览
- 双图同步对照、会话标记及 CSV 导出
- 内嵌调色盘、实时背景预览及取消恢复
- 界面风格、文字大小、紧凑控件及 JSON 主题
- 支持的动图播放与暂停，受资源限制约束
- PNG、JPEG、GIF、WebP、AVIF、BMP、TIFF 和 ICO
- 本机固定磁盘回收站删除
- 按 AGPLv3 条款免费个人及商业使用
