# 映窗（YingView）

映窗是一款面向 Windows 10 和 11 的本地图片查看器。打开图片或拖入文件夹，就能在宽阔、清爽的窗口里浏览。应用使用 .NET 10 与 WPF 构建，图片解码由 Magick.NET 15 提供。下载简体中文版本会使用“映窗”名称和中文界面；下载英文版本则使用 YingView 名称和英文界面。

**版本：**0.3.5 预览版 · **架构：**x64

[English](README.md) · [从 GitHub Releases 下载](https://github.com/shixi-11/yingview/releases) · [主题说明](docs/themes.md)

## 功能

- 默认以最大化窗口打开图片，按比例完整显示；小图也会自动放大。
- 滚轮围绕指针位置缩放，放大后可拖动画面。方向键可按文件名自然顺序浏览当前文件夹。
- 工具栏保持简洁，缩略图栏默认收起；按 **T** 显示或隐藏。
- 看图区默认使用统一的纯黑背景。点击工具栏 **◐** 或按 **B**，可将整块背景切换为黑色或白色，并记住选择。
- 并排对比两张图片，缩放和平移保持同步。可选择深色、浅色或棋盘格背景，为图片标记“保留”或“待定”，并将本次标记导出为本地 CSV 文件。
- 按 **Delete** 或 **Del** 将当前图片移入 Windows 回收站。此功能支持本机固定磁盘；网络驱动器和可移动磁盘暂不支持。
- 动图受200帧、解码帧总量256 MiB和单张图片1亿像素限制。TIFF文件打开第一页。
- 提供四种内置风格、即时配色与文字大小调整、紧凑工具栏，以及免费导入和导出 JSON 主题。简体中文版本使用中文界面，英文版本使用英文界面；其他语言使用英文。

外观编辑器现在提供主题预览卡片、颜色选项和文字预览，对照窗口也会跟随界面字号调整。打开空文件夹、损坏文件或已移动的图片时，会清除之前的选择并提供恢复提示；按 **F5** 可刷新当前图片，文件已移动时会重新读取所在文件夹。

独立版点击“更多 → 设为默认看图软件”，再点击“确认并设置全部”，即可批量设置全部 10 种支持的图片格式。应用会检查 Windows 实际生效的关联，未能设置的格式会如实显示。商店安装包使用 Windows 系统设置流程。

## macOS 预览版

macOS 原生客户端位于 `src/YingView.macOS`，使用 SwiftUI、AppKit 和系统 ImageIO，支持 macOS 13 及以上。它提供完整显示、物理像素100%、翻图、缩放、旋转、废纸篓、可折叠缩略图、双图对照和外观设置。构建脚本为中英文分别生成包含 Apple silicon 与 Intel 架构的应用。此版本仍需完成苹果开发者签名与公证，尚未上架 Mac App Store。

解码器已配置处理 PNG、JPEG、GIF、WebP、AVIF、BMP、TIFF、ICO、HEIC 和 HEIF 扩展名。能否打开取决于文件编码与内容；HEIC 和 HEIF 在此版本中尚未验证。

## 图片处理与隐私

映窗在本机打开和对比图片。查看、旋转和镜像不会改动图片数据。应用不会上传图片内容，不含广告，也不会发送使用数据分析信息。图片文件只会在你明确使用回收站命令时被移入回收站。更多本地数据说明见[隐私信息](docs/store/privacy.zh-CN.md)。

## 下载与构建

本仓库包含面向 Windows x64 的 0.3.5 预览版源码。当前可下载的版本请以 [GitHub Releases](https://github.com/shixi-11/yingview/releases) 标注为准，源码更新不会自动发布新的下载文件。Microsoft Store 提交尚未进行。

请按偏好选择对应语言的下载文件。所选版本也决定应用名称、图标和安装后的快捷方式语言。

从源码构建需要安装 .NET 10 SDK，然后运行：

```powershell
.\scripts\build.ps1
```

生成的 `Install.ps1` 支持 `-KeepRunningVersion`：在保留当前运行窗口的情况下独立安装更新并切换快捷方式。之后从更新后的快捷方式重新打开应用，即可使用新版。
