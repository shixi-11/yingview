# 映窗

完整看图，再细看不同。映窗是一款由光之十一开发的免费开源图片查看器。打开图片或文件夹，即可在清爽的最大化窗口中按比例完整查看，按文件名自然顺序翻阅，或将两张图片并排对照。选片网格支持多选、收藏、批量回收站删除和任选两张对比。黑、白、灰、棋盘格和自选颜色背景，方便检查画面与透明边缘。图片始终在本机处理。

## Windows 版能做什么

| 你想做的事 | 映窗提供的功能 |
| --- | --- |
| 完整看到整张图片 | 打开后窗口最大化，小图自动按比例放大；完整显示保留整张画面，100% 则按物理像素查看。 |
| 顺手翻阅文件夹 | 打开或拖入图片、文件夹，按文件名自然顺序翻图，需要时展开紧凑缩略图栏。 |
| 检查画面细节 | 围绕指针缩放、拖动画面、旋转或镜像查看、显示图片信息，以及全屏浏览。 |
| 看清透明区域 | 一键切换整个画布的黑、白、灰和棋盘格背景；在图片旁展开调色盘，拖动或输入色号实时预览，确认保存、取消恢复。 |
| 对比不同方案 | 两张图片并排显示，同步缩放和平移，标记“保留”或“待定”，导出本次标记为本地 CSV。 |
| 完成常用操作 | 复制图片或路径、粘贴图片、打开最近记录、在文件夹中定位；Delete/Del 将支持的本机文件移入 Windows 回收站。 |
| 调整观看环境 | 四种界面风格、自定义配色、文字大小、紧凑工具栏，以及 JSON 主题导入和导出。 |
| 查看动图与幻灯片 | 播放或暂停支持的动图，也可自动轮播文件夹中的图片。 |
| 安装与更新 | 独立版更新检查、安装助手，以及会核对实际关联结果的默认看图软件设置。 |

调色盘嵌入主界面右侧，与图片并排；完整显示模式会随可用空间调整，不用额外弹窗盖住画面。“背景”按钮循环切换四种预设；**B** 只切换黑白，**T** 展开或收起缩略图，**F** 完整显示，**1** 查看实际像素，**V** 打开对照，**F11** 切换全屏。

### 摄影师与客人选片

点击工具栏的“选片”，或按 **Ctrl+Shift+P**，进入照片网格。点击“打开文件夹”选择整组照片，也可把文件夹或多张图片直接拖入网格；无需逐张导入。按住 **Ctrl** 逐张多选，按住 **Shift** 连选；选中一张即可开始对比，可在对比窗口换图；选中两张时直接对比指定的两张。双击进入完整预览，用左右方向键切换图片，返回时定位到刚看的照片。

“收藏”会保存到本机，下次打开仍然保留；可只看收藏，并导出收藏照片的文件名清单。支持将多张照片一次确认后移入回收站；失败的文件会保留，不会转为永久删除。可选每页 2、4、6、8、12、16 或 24 张，并独立调节缩略图大小。两项设置会保存，选择可跨页保留。

“清空导入”清除当前列表；右键“移出本次选片”只移出所选条目。两者都保留原文件和收藏。右键“移动到文件夹”可整理原文件，同名项目跳过，移动成功的收藏会随文件更新。

照片与收藏在本机处理，可导出文件名清单交回摄影师。本版不包含 RAW 专用流程、星级评分、修图或云端交付。

### 格式与处理范围

支持 PNG、JPEG、GIF、WebP、AVIF、BMP、TIFF 和 ICO。TIFF 查看第一页。程序识别 HEIC/HEIF 扩展名，但本版尚未完成其兼容性验证。

动图最多 200 帧，单张图片最多 1 亿像素。较大的动图会使用临时磁盘帧缓存，避免把全部解码帧留在内存；256 MiB 是内存切换阈值，不是统一的文件大小上限。临时解码帧总量上限为 2 GiB，解码器本身的资源限制也可能更早拒绝复杂文件，不保证所有编码和动图均可打开。

回收站删除支持本机固定磁盘，不支持网络盘和可移动磁盘。

## 语言与安装

下载 **YingView-zh-CN.exe** 使用中文客户端，下载 **YingView-en-US.exe** 使用英文客户端。下载版本决定界面、显示名称、图标和安装快捷方式的语言；暂未翻译的其他语言使用英文。

直接运行下载的程序即可看图。需要安装快捷方式和注册文件关联时，可使用本地构建随附的安装助手。默认看图软件设置会检查 Windows 实际关联了哪些支持的图片格式。

启用自动检查后，应用会在首个窗口显示后检查更新，每天最多一次；下载和安装由你选择。商店管理的客户端使用商店更新渠道。详见[更新说明](docs/updates.md)。

## macOS 原生预览版

仓库另含基于 SwiftUI、AppKit 和 ImageIO 的 macOS 13 及以上原生客户端，已有图片及文件夹打开、完整显示和物理像素查看、翻图、缩放、旋转、废纸篓、缩略图、外观设置及选片网格、Cmd/Shift 多选、批量废纸篓删除和任选两张对比，尚未包含上表全部 Windows 功能。

构建脚本可生成独立的中文和英文应用，包含 Apple silicon 与 Intel 架构。Developer ID 签名、公证和 Mac App Store 提交尚未完成；下载以实际发布的文件为准。

## 隐私

浏览、旋转和镜像查看不会覆盖原始图片文件。映窗不上传图片、不显示广告、不发送使用数据分析。偏好和最近路径留在本机；大动图可能生成临时解码帧，选片收藏会保存在本机，选片清单可导出为文件名 TXT；原有对比会话标记可导出为 CSV。自愿支持入口通过浏览器打开。详见[隐私说明](docs/store/privacy.zh-CN.md)。

## 从源码构建

Windows 版使用 .NET 10、WPF 和 Magick.NET 15。安装 .NET 10 SDK 后运行：

```powershell
.\scripts\build.ps1
```

脚本会构建中英文独立客户端。macOS 构建说明见 [src/YingView.macOS](src/YingView.macOS)，微软商店打包资料见 [docs/store](docs/store)；应用尚未提交商店。
